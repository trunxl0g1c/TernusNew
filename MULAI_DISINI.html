TERNUS v1.1

Inventory modular untuk XAMPP

Inventory, produksi kopi, penjualan, dan inventaris kantor dalam satu aplikasi.

Sudah memakai versi sebelumnya?

Backup database dan simpan konfigurasi lama sebelum mengganti folder aplikasi. Ikuti docs/UPGRADE.md. Gunakan kembali server/config.php milik Anda agar data lama tetap terbaca. Tidak perlu membuat akun owner baru atau mengimpor ulang master.

Pemasangan pertama

  1. Salin folder ternus ke C:\xampp\htdocs\ternus.
  2. Aktifkan Apache dan MySQL di XAMPP.
  3. Buka http://localhost/ternus/index.html.
  4. Buat akun owner. Database dan master awal dibuat otomatis.
  5. Login, tinjau data barang, tambahkan vendor/pelanggan, lalu input penerimaan.

Untuk programmer

Mulai dari docs/DEVELOPER.md. Backend berada di app/Modules, frontend di assets/js/modules, dan sumber Tailwind di resources/css.

Jalankan npm ci dan npm run watch:css untuk mengembangkan styling. Hasil build lokal sudah disertakan, sehingga penggunaan aplikasi sehari-hari tidak membutuhkan npm, Composer, atau koneksi internet.

Gunakan PHP 8.1+. Bila password/port database berbeda, edit server/config.php. Aplikasi harus dibuka melalui localhost. Saldo awal instalasi baru kosong; 89 master barang tersedia untuk ditinjau.

Arsitektur modular monolith. Belum merupakan deployment microservice. Hasil pengujian dan batas fitur tersedia di README.md dan HASIL_PENGUJIAN.md.
